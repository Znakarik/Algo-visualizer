# algo-visualizer

Конструктор и пошаговый визуализатор алгоритмов фильтрации (карты, параметры, правила).
Подробности — в README.md.

- Если задача — собрать фильтры/ветвления из другого кода в файлы алгоритмов, следуй
  AGENT_INSTRUCTIONS.md.
- Проверка файлов алгоритмов: `node tools/validate.js --today <YYYY-MM-DD> algorithms/*.algo.json`.
- Тесты: `npm test` (интерфейсные тесты нужен Playwright; без него пропускаются).
- Без зависимостей: чистый JS, Node.js 18+.

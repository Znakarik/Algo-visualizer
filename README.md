# Конструктор алгоритмов (algo-visualizer)

Визуализатор **своих** алгоритмов, а не только стандартных сортировок.
Алгоритм собирается из блоков, а затем проходится по шагам: на каждом шаге видно,
какие данные пришли в блок и что из него вышло.

## Блоки

| Блок | Что делает | Пример выражения |
|---|---|---|
| Входные данные | JSON-массив или значения через запятую | `[1, 2, 3]`, `[{"name":"Аня","age":20}]` |
| Фильтр | оставляет элементы, для которых условие верно | `x > 2` |
| Преобразование | меняет каждый элемент | `x * 10`, `x.name` |
| Ветвление | делит элементы на ветки «да»/«нет», у каждой свои блоки; потом ветки сливаются (сначала «да», затем «нет») | `x % 2 === 0` |
| Утверждение | проверяет условие для каждого элемента, подсвечивает нарушения; может останавливать алгоритм | `x >= 0` |
| Сортировка | сортирует по ключу | `x.age` |
| Свёртка | сворачивает массив в одно значение | `acc + x`, `Math.max(acc, x)` |

В выражениях доступны: `x` — элемент, `i` — индекс, `data` — весь массив, `acc` — накопитель (в свёртке).
Выражения — обычный JavaScript.

## Как запустить

Открыть `index.html` в браузере (двойной клик). Схема сохраняется в браузере автоматически,
её можно выгрузить и загрузить через «Импорт / экспорт» (JSON).

Один файл со всем внутри: `node build.js` → `dist/algo-visualizer.html`.

Управление шагами: кнопки или клавиши ← → и пробел. Клик по блоку — переход к его шагу.

## Тесты

```
npm test
```

- `tests/engine.test.js` — движок (выполнение, ветки, утверждения, ошибки).
- `tests/ui.test.js` — интерфейс в браузере через Playwright. Если Playwright не установлен, тест пропускается.
  Установить: `npm i -D playwright && npx playwright install chromium`.

## Устройство

- `engine.js` — движок без интерфейса: `run(blocks)` возвращает результат и трассу шагов.
- `app.js` — редактор блоков и просмотр шагов.
- `styles.css`, `index.html` — оформление и разметка.

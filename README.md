# Конструктор алгоритмов (algo-visualizer)

Визуализатор **своих** алгоритмов фильтрации, а не только стандартных сортировок.
Алгоритм собирается из блоков, условия накликиваются из выпадающих списков,
а результат проходится по шагам. На каждом шаге видно, какие элементы прошли,
какие отброшены и какое именно правило сработало.

Основной сценарий: на входе набор параметров (флаги и числа: «кредитные разрешены»,
«есть минимальная сумма», «минимальная сумма») и массив карт с полями
(тип, баланс, срок действия, валюта…). На выходе получается отфильтрованный массив карт.

## Как запустить

Открыть `index.html` в браузере (двойной клик).

Один файл со всем внутри: `node build.js` → `dist/algo-visualizer.html`.

## Входные данные

Первый блок задаёт:

- **Параметры**: имя, тип (да/нет, число, строка, дата) и значение. Список можно расширять кнопкой «+ параметр».
  Их же можно быстро переключать в панели «Параметры» над результатом.
- **Элементы**: JSON-массив объектов. Поля подхватываются автоматически и появляются в выпадающих списках.
  Вложенные поля доступны через точку (`owner.age`).

Срок действия понимается в форматах `"2027-03"`, `"03/27"` (как на карте), `"2027-03-31"`, `"31.03.2027"`.
Если день не указан, карта считается действующей до конца месяца.

## Блоки

| Блок | Что делает |
|---|---|
| Фильтр | оставляет элементы, для которых условие верно: **все совпавшие** или **только первую совпавшую** |
| Ветвление | делит элементы на ветки «да»/«нет», у каждой свои блоки; потом ветки сливаются (сначала «да», затем «нет»). В режиме «только первая» в «да» идёт первая совпавшая, остальные в «нет» |
| Утверждение | проверяет, что условие верно для каждого элемента, и подсвечивает нарушения; может останавливать алгоритм |
| Сортировка | сортирует по полю (числа, строки, даты) |
| Преобразование | меняет каждый элемент (выражение JS) |
| Свёртка | сворачивает массив в одно значение (выражение JS) |
| Возврат | ранний выход, как `return` в Java: если сработал (всегда / есть совпавшие / совпавших нет), весь алгоритм сразу заканчивается с результатом (совпавшие / первая совпавшая / весь список / пустой), даже изнутри ветки. Невыполненные блоки показываются серыми |

### Условия

Условие состоит из правил: **что проверяем** (поле элемента или параметр), **операция**
(`=`, `≠`, `>`, `≥`, `<`, `≤`, содержит, да, нет, задано, не задано) и **с чем сравниваем**
(значение, параметр, другое поле, сегодня). Правила объединяются через «все (И)» или «хотя бы одно (ИЛИ)».

Примеры:
- «кредитные разрешены»: `p.creditAllowed да` **ИЛИ** `type ≠ credit`;
- «минимальная сумма»: `p.hasMinAmount нет` **ИЛИ** `balance ≥ параметр minAmount`;
- «не истекла»: `expires ≥ сегодня`.

Переключатель «Код» позволяет записать условие выражением JS. Там доступны `x` (элемент), `p` (параметры), `i` (номер), `data` (весь массив).

## Сохранение

- **Сохранить в файл** записывает алгоритм во внешний файл `<название>.algo.json`. Это основной
  способ хранить алгоритмы между сессиями: файлы можно класть в папку `algorithms/` и коммитить.
  - В Chrome/Edge (страница открыта с диска) файл выбирается один раз, а дальше «Сохранить» (Cmd+S)
    перезаписывает его же. Привязанный файл виден рядом с кнопками, «×» отвязывает его.
  - В опубликованной версии на claude.ai файл сохраняется через окно подтверждения.
  - В остальных браузерах файл скачивается в «Загрузки».
- **Открыть файл** загружает `.algo.json`.
- **Сохранить** кладёт алгоритм в список «Мои алгоритмы». В опубликованной версии на claude.ai
  список хранится на сервере и доступен с любого устройства. Локально он хранится в браузере
  и может пропасть при очистке данных сайта.
- **JSON** показывает алгоритм текстом, чтобы его можно было скопировать или вставить.

В файле, кроме блоков, могут быть `description`, `source` и `scenarios` (проверочные запуски
с другими параметрами). Конструктор их сохраняет.

## Проверка файлов алгоритмов

```
node tools/validate.js --today 2026-10-22 algorithms/*.algo.json
```

Скрипт выполняет каждый алгоритм тем же движком, прогоняет сценарии и сообщает об ошибках
(ссылки на несуществующие параметры, неверный формат, несовпадение со сценарием) и
предупреждениях (правило не покрыто тестовыми данными, опечатка в поле).

## Тесты

```
npm test
```

- `tests/engine.test.js` проверяет движок: параметры, правила, даты, ветки, утверждения, ошибки, сохранение.
- `tests/validate.test.js` проверяет скрипт `tools/validate.js`.
- `tests/ui.test.js` проверяет интерфейс в браузере через Playwright. Если Playwright не установлен, тест пропускается.
  Установить: `npm i -D playwright && npx playwright install chromium`.

## Устройство

- `engine.js`: движок без интерфейса. `run(blocks)` возвращает результат и трассу шагов.
- `examples.js`: готовые примеры.
- `app.js`: редактор блоков, просмотр шагов, сохранение.
- `styles.css`, `index.html`: оформление и разметка.
